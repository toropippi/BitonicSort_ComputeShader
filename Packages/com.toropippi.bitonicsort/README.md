# Bitonic Sort Compute Shader

This package provides a Unity compute shader implementation of the Bitonic sort algorithm.

codex/create-unity-package-structure
Add the following line to your `manifest.json` to use this package from GitHub:
```json
"com.toropippi.bitonicsort": "https://github.com/toropippi/BitonicSort_ComputeShader.git"
```
